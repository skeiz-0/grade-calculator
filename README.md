
# Grade Calculator

**Name:** ALEXANDRA KEI S. TORREON

**Section:** IT3R4

## Description
This is a simple JavaScript program that calculates the average of three grades and determines whether the student passed or failed. A grade of 75 or above is considered passing.

## How to Run
1. Install Node.js on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

   node index.js

## Sample Output
Grade Calculator
Grade 1: 90
Grade 2: 85
Grade 3: 88
Average Grade: 87.67
Result: Passed
